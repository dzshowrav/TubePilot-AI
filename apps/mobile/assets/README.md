# Asset provenance

- `studio-hero.png` is an AI-generated product illustration created for TubePilot AI. It is not a
  photograph, a YouTube asset, or a preview of a live generation feature.
- Sample video-cover illustrations are original SVG components in `../src/components/visuals.tsx`.
- Inter, Manrope and Noto Sans Bengali are supplied by their `@fontsource` packages under the
  included SIL Open Font License. Lucide icons retain the package's license.
- Sample channel names, metrics, topics and video titles are fictional demonstration content.

- `app-icon.png` and `adaptive-foreground.png` are original TubePilot launcher artwork. Regenerate
  them with `python3 scripts/android/create-icons.py` (Python standard library only).
